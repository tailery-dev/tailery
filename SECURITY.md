# Security Policy

The Tailery team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose findings.

## Supported Versions

Only the latest release of Tailery receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in Tailery, please **do not open a public issue**. Instead, follow this procedure:

1. **Email the Maintainers**: Send a detailed report to **vlad.fratila@gmail.com** or open a [Private Vulnerability Advisory](https://github.com/tailery-dev/tailery/security/advisories/new) on GitHub.
2. **Include Necessary Details**:
   - A clear description of the vulnerability.
   - Steps to reproduce the issue (including any sample configs or payloads).
   - Affected versions and operating systems.
   - Potential impact of the vulnerability.
   - (Optional) Suggested remediation or patch.

## Response SLA

- **Acknowledgment**: Within 48 hours of receipt.
- **Assessment & Triage**: Within 5 business days.
- **Remediation & Advisory**: We will work with you to coordinate disclosure timing and publish a patch and security advisory acknowledging your contribution.

Thank you for helping keep Tailery and the MCP ecosystem safe!
