# Tailery

Welcome to the **Tailery** documentation!

Tailery is an open-source Model Context Protocol (MCP) and skill manager tailored for Coding Assistants. Whether you are using Cursor, Claude Code, Zed, or Antigravity, Tailery acts as the central hub connecting all your tools, sandboxes, and integrations to your AI assistants.

## Why Tailery?

As the Model Context Protocol (MCP) ecosystem grows, managing server configurations for different IDEs and tools becomes repetitive and error-prone. Tailery solves this by providing:

1. **A Single Source of Truth**: Configure your MCP servers and AI skills once in Tailery.
2. **Seamless Syncing**: Sync your configurations instantly to supported IDEs and CLI tools.
3. **Beautiful TUI**: A built-in Terminal User Interface (TUI) to toggle tools on and off.
4. **Sandboxed Environments**: Native Docker integration to run your servers in isolated environments securely.
